# ADR-0001. Єдиний backend для однієї теплиці

Статус: прийнято; зафіксовано у С9 (24.11.2026).

## Контекст

REST, live-канал, авторизація і запис телеметрії працюють з однією SQLite.

## Розглянуті варіанти

1. Моноліт Node.js — один процес і спільний контроль доступу.
2. Мікросервіси — незалежне масштабування, але більше мережевих викликів, складніший Compose та узгодження транзакцій.

## Рішення

Моноліт. Для масштабу навчальної теплиці простота розгортання важливіша за незалежне масштабування.

## Наслідки

Збій процесу впливає і на REST, і на Socket.IO; при зростанні навантаження можливе розділення.

Підтвердження в коді: `server.js`, `realtime/bridge.js`, `compose.yaml`.
