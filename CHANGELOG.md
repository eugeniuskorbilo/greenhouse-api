# Changelog

Істотні зміни проєкту фіксуються за структурою Keep a Changelog.

## [1.0.0] - 2026-11-24

### Added

- REST API пристроїв, телеметрії, порогів і аудиту; MQTT та Socket.IO.
- Вебдашборд, JWT access/refresh, рольовий доступ.
- Flutter-клієнт попереднього етапу ПР5.
- Unit, integration, API, negative, property, mutation та браузерні тести.
- Docker Compose, health, метрика підключень, GitHub Actions і GHCR.
- C4, OpenAPI, ADR, матриця трасованості, пояснювальна записка та сценарій захисту.

### Changed

- README уточнює окремий запуск React, початкове заповнення БД та межі мобільної інтеграції.
- Додано CI документації та сценарій локального демонстраційного запуску.
